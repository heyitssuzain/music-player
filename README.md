# AURA — Music, beautifully simple.

![AURA Hero](app/src/main/res/drawable/aura_anime_character.jpg)

AURA is a high-performance, dark-themed music player engineered for Android phones, tablets, and foldables. Built natively with Jetpack Compose, Material 3, AndroidX Media3 (ExoPlayer), Room SQLite database, and deterministic speech recognition.

---

## Highlights

- 🌟 **Cinematic Anime Landing Page:** Atmospheric dark aesthetic with an original anime protagonist centerpiece, subtle glowing rim lighting, ambient Canvas particle motion, and smooth transitions.
- 🔓 **100% No-Authentication Experience:** Zero login, registration, password prompts, or cloud accounts required. All features work immediately out-of-the-box.
- 🎵 **True Native Media3 Engine:** Foreground service playback, background audio, lock-screen controls, notification actions, and audio focus management.
- 🔍 **Real YouTube Search & Streaming:** Resilient online music search with 400ms debouncing, URL encoding supporting English and Hindi/Hinglish queries, and direct stream resolution.
- 📂 **Local Music Library:** Instant scanning of device audio files with album art, artist, and album categorization.
- 💾 **Offline Storage:** SQLite (Room) persistence for tracks, playlists, favorites, listening history, downloads, and app settings.
- 🎙️ **Voice Control:** Push-to-talk speech recognition supporting English and Hindi/Hinglish commands with zero external paid AI fees.
- ⚡ **Zero-Dependency APK Builds:** Complete cloud builds via GitHub Actions (`.github/workflows/android-ci.yml`), delivering ready-to-install debug and release APKs without requiring local Android Studio or SDK installation.
